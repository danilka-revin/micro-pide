# Установка и запуск MicroPIDE

MicroPIDE — веб-среда разработки для Arduino: работает в браузере, а компиляция,
прошивка и монитор порта выполняются локально через `arduino-cli`.
Есть **единый установщик**, который сам ставит всё необходимое и запускает среду.

---

## Требования

| Что | Версия / примечание |
|---|---|
| ОС | Linux, macOS или Windows 10/11 |
| Node.js | 18+ (установщик поставит сам, если нет) |
| arduino-cli | любой свежий (установщик скачает сам) |
| Браузер | Chrome / Firefox / Edge последних версий |
| Интернет | нужен только на время установки и обновлений |

Права администратора нужны **только** если на машине нет Node.js и установщик
ставит его через пакетный менеджер. Всё остальное (arduino-cli, платы, скетчи)
живёт в каталоге `.data/` внутри программы и систему не трогает.

---

## Быстрый старт

```bash
git clone https://github.com/danilka-revin/micro-pide.git
cd micro-pide
./install.sh
```

Установщик сделает всё сам и в конце напечатает адрес — откройте
**http://localhost:8080**. Всё.

### Ключи установщика (Linux/macOS)

```bash
./install.sh --port 3000   # другой порт
./install.sh --no-avr      # не ставить платформу Arduino AVR (Uno/Nano/Mega)
./install.sh --no-run      # установить, но не запускать
./install.sh --no-desktop  # без ярлыка (по умолчанию ярлык ставится на рабочий стол и в меню приложений, Linux)
```

### Windows

```bat
git clone https://github.com/danilka-revin/micro-pide.git
cd micro-pide
install.cmd
```

`install.cmd` поставит Node.js через winget (если нет), соберёт программу,
скачает arduino-cli, поставит платформу AVR и откроет браузер.

### Что именно делает установщик

1. **Node.js 18+** — если не найден: apt/NodeSource, dnf, pacman, zypper или
   Homebrew; если и их нет — официальный архив Node.js в `.data/node`
   (без прав root).
2. **Зависимости npm** — `npm ci` (или `npm install`).
3. **Сборка** — `npm run build`, фронтенд попадает в `dist/`.
4. **arduino-cli** — последний релиз с GitHub в `.data/bin/`. Если у вас уже
   есть системный `arduino-cli`, он будет использован вместо скачивания.
5. **Платформа Arduino AVR** (Uno, Nano, Mega) — ставится, только если её ещё
   нет; если у вас установлена Arduino IDE с платами, они подхватятся из её
   каталога и ничего качать не придётся.
6. **Проверка прав на порты** (Linux): если вас нет в группе `dialout`,
   установщик подскажет команду `sudo usermod -aG dialout $USER`.

Повторный запуск установщика безопасен: всё уже поставленное не перекачивается.

## Проекты и библиотеки Arduino IDE

MicroPIDE **автоматически подхватывает вашу Arduino IDE**, если она установлена:

- **Скетчбук**: `~/Arduino` (Linux) или `~/Documents/Arduino` (Windows/macOS).
  Все ваши проекты появляются в панели «Скетчи» (вложенные папки тоже), их
  можно открывать, править и прошивать прямо там же, где их хранит Arduino IDE.
- **Библиотеки**: папка `libraries/` внутри скетчбука — библиотеки, поставленные
  через Arduino IDE, видны в панели «Библиотеки» с меткой **IDE** и доступны
  при компиляции.
- **Платы**: каталог данных `~/.arduino15` (Linux),
  `~/Library/Arduino15` (macOS), `%LOCALAPPDATA%\Arduino15` (Windows) —
  установленные в Arduino IDE платформы и платы видны в MicroPIDE с меткой
  **IDE**, даже до установки arduino-cli.

Если автоматика не сработала или папка проектов в другом месте —
**Настройки (Ctrl+,) → Общие → Скетчбук**: укажите путь вручную (например,
`/home/user/Arduino`) или выберите источник «Внутренний каталог». Смена
действует сразу, без перезапуска.

Свои `.ino`-файлы можно импортировать кнопкой **«Импорт .ino»** в панели
«Скетчи» — они скопируются в скетчбук как отдельный проект.

## Как пользоваться после установки

1. Откройте `http://localhost:8080`.
2. Слева панель: **Скетчи** (ваш скетчбук), **Примеры**, **Библиотеки**,
   **Платы**.
3. В шапке выберите **плату** и **порт** (плата появится, когда установлена её
   платформа; порт — когда воткнута плата).
4. **Проверить** (Ctrl+R) — компиляция; **Загрузить** (Ctrl+U) — прошивка.
5. **Монитор порта** внизу — отправка/приём данных, **Графики** — построитель
   для числовых строк.

Обновление: кнопка **«Обновить»** в шапке сама подсвечивается, когда в репозитории
выходит новая версия; по клику — прогресс и автоматический перезапуск.

## Автозапуск как службы (по желанию, Linux)

```bash
sudo tee /etc/systemd/system/micropide.service >/dev/null <<EOF
[Unit]
Description=MicroPIDE — среда Arduino
After=network.target

[Service]
User=$USER
WorkingDirectory=$(pwd)
ExecStart=$(which node) server/server.mjs 8080
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now micropide
```

## Запуск для разработки

```bash
npm install
npm run server     # API на :8080
npm run dev        # vite-dev на :5173 (проксирует API на 8080)
```

## Устранение неполадок

**«Порт не открывается» / Permission denied (Linux)**
Добавьте себя в группу `dialout` и перелогиньтесь:
`sudo usermod -aG dialout $USER`.

**«arduino-cli не найден»**
Нажмите «Установить arduino-cli» в панели «Платы» или запустите
`node scripts/install-cli.mjs`. Проверьте интернет — утилита качается с GitHub.

**Плата есть в Arduino IDE, но не видна в MicroPIDE**
Откройте Настройки → Общие → Скетчбук и убедитесь, что источник — «папка
Arduino IDE». Список плат обновляется кнопкой ⟳ в шапке.

**Прошивка не стартует, пока открыт монитор порта**
Так и задумано: порт занят монитором — он закрывается автоматически перед
прошивкой.

**Port 8080 уже занят**
Запустите на другом порту: `./run.sh 3000` (или `install.cmd 3000`).

**Сборка не удалась при обновлении**
Старая версия остаётся рабочей; подробный лог виден в диалоге обновления
(«Подробности»).

## Где что лежит

| Путь | Что это |
|---|---|
| `.data/sketchbook/` | внутренний скетчбук (если не используется папка Arduino IDE) |
| `.data/bin/` | скачанный arduino-cli |
| `.data/arduino15/` | платформы и индексы (внутренний режим) |
| `.data/config.json` | настройки каталогов (скетчбук, источник) |
| `dist/` | собранный фронтенд |
| `~/Arduino`, `~/Documents/Arduino` | ваш скетчбук из Arduino IDE (используется напрямую) |
