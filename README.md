# MicroPIDE

**MicroPIDE** — свободная среда разработки для Arduino: редактор скетчей, компиляция,
прошивка, монитор порта и построитель графиков. Всё, что делает Arduino IDE в
повседневной работе, — в веб-интерфейсе, который можно открыть в браузере на машине,
где воткнута плата.

Дизайн, система тем/пресетов и автообновление унаследованы от
[PSBees / linux_pcb_app](https://github.com/danilka-revin/linux_pcb_app): фирменный
«пчелиный» стиль (золото на графите), тот же движок «Обновить с main», те же пресеты
тем (Dracula, Nord, Monokai, Tokyo Night, Матрица и ещё ~30) и свои профили настроек.

## Возможности

**Скетчи (как в Arduino IDE)**
- редактор C++ на CodeMirror 6: подсветка, автодополнение, пары скобок, поиск/замена (Ctrl+F), свёртка;
- вкладки файлов скетча (.ino, .cpp, .h, .c, .S, .hpp), добавление/закрытие файлов;
- скетчбук на диске сервера (`data/sketchbook`): открыть/сохранить/сохранить как/переименовать/удалить;
- автосохранение черновика в браузере;
- встроенные примеры (Blink, BlinkWithoutDelay, Fade, ToneMelody, Debounce, Smoothing,
  AnalogInOut, SerialEvent, Graph, Dimmer…) + примеры установленных плат и библиотек.

**Железо**
- компиляция (`Проверить`, Ctrl+R) и прошивка (`Загрузить`, Ctrl+U) через `arduino-cli`;
- выбор платы (все платы установленных ядер) и порта прямо в шапке, опрос портов раз в 4 с;
- менеджер плат: поиск и установка ядер (`arduino:avr`, `esp32`, …), удаление;
- менеджер библиотек: установленные / поиск по индексу / установка / удаление;
- установка самого `arduino-cli` одной кнопкой (скачивается с GitHub в `data/bin`, без системных прав);
- монитор порта: скорость до 115200, отправка строк с выбором конца строки, автопрокрутка, штампы времени;
- построитель графиков: рисует числа, которые печатает устройство (до 8 каналов).

**Оформление и настройки (порт из PSBees)**
- ~30 готовых тем + свои темы (свой акцент/фон/панели/текст), сохранение и удаление;
- пресеты вида интерфейса (Стандартный/Ноутбук/Минимализм/Отладка);
- свои профили настроек: вся конфигурация одним кликом;
- экспорт/импорт настроек файлом `micropide-settings.json`;
- настройки редактора (размер шрифта, перенос строк, показ пробелов), монитора порта, сборки.

**Автообновление (порт из PSBees)**
- фоновая проверка ветки `main` на GitHub: кнопка «Обновить» сама загорается и пульсирует;
- диалог с интерактивной полосой прогресса: этапы, скорость, ETA, отмена;
- два пути обновления: git-клон (`fetch` + `merge --ff-only`) или tar.gz-установка
  (скачивание → зависимости → сборка → подмена файлов, старая версия в `.update-cache/backup`);
- после установки сервер сам перезапускается, страница дожидается новой версии и перезагружается.

## Запуск

### Быстро — единый установщик

```bash
./install.sh        # Linux/macOS: поставит Node.js (если нет), зависимости, arduino-cli,
                    # платформу AVR и запустит на :8080
```

Windows: `install.cmd`. Подробный гайд — [INSTALL.md](INSTALL.md).

### Вручную

Нужен Node.js 18+.

```bash
./run.sh            # поставит зависимости, соберёт фронтенд и запустит сервер на :8080
./run.sh 3000       # на другом порту
./run.sh --build    # принудительная пересборка
```

Открыть `http://localhost:8080`. Разработка: `npm run dev` (vite, API проксируется на :8080)
и рядом `npm run server`.

### Проекты и библиотеки Arduino IDE

Если установлена Arduino IDE, MicroPIDE сам подхватывает её папки: проекты из
скетчбука (`~/Arduino` / `~/Documents/Arduino`), библиотеки из `libraries/` и
платы из `Arduino15` — с меткой **IDE** в панелях. Каталог можно сменить в
Настройках (Ctrl+,) в любой момент.

### arduino-cli

Без `arduino-cli` редактор и оформление работают, но компиляция/прошивка/монитор — нет.
Нажмите «Установить arduino-cli» в панели **Платы** — утилита скачается в `data/bin`
(данные: каталог `data`, скетчбук `data/sketchbook`; переопределяется переменными
`MICRO_PIDE_DATA` и `MICRO_PIDE_SKETCHBOOK`). Плоды ставятся в тот же каталог —
систему MicroPIDE не трогает. Можно и системный `arduino-cli` — он подхватится из PATH.

Порт сериального моста: сперва используется пакет `serialport` (опциональная зависимость),
если его нет — `arduino-cli monitor`.

## Структура

```
server/
  server.mjs         — HTTP-сервер: статика dist/, API, /version, /update/* (схема PSBees)
  arduino.mjs        — обёртка arduino-cli: поиск, установка, платы, библиотеки, compile/upload
  serialbridge.mjs   — серийный мост: serialport → arduino-cli monitor, буфер строк
  updater.mjs        — движок автообновления (check/run/status/cancel) — перенос PSBees
  sketches.mjs       — скетчбук на диске
scripts/
  write-version.mjs  — dist/version.json (SHA сборки для автообновления)
src/
  App.tsx            — весь интерфейс: шапка-меню, панели, редактор, низ, статус-строка
  ui/                — дизайн-система PSBees: styles.css, icons, widgets, prefs, palette,
                       presets (темы), settings, updater (диалог обновления)
  ide/               — специфика IDE: api-клиент, редактор, примеры, консоль, монитор, панели
test/server.mjs      — смоук-тест сервера (npm test)
```

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Проверить (компилировать) | `Ctrl+R` |
| Загрузить в плату | `Ctrl+U` |
| Сохранить | `Ctrl+S` |
| Новый скетч | `Ctrl+N` |
| Открыть из скетчбука | `Ctrl+O` |
| Найти | `Ctrl+F` |
| Закомментировать строку | `Ctrl+/` |
| Монитор порта | `Ctrl+Shift+M` |
| Настройки | `Ctrl+,` |
