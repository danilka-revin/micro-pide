# MicroPIDE

**MicroPIDE** — свободная среда разработки для Arduino: редактор скетчей, компиляция,
прошивка, монитор порта и построитель графиков. Всё, что делает Arduino IDE в
повседневной работе, — в веб-интерфейсе, который можно открыть в браузере на машине,
где воткнута плата.

Дизайн, система тем/пресетов и автообновление унаследованы от
[PSBees / linux_pcb_app](https://github.com/danilka-revin/linux_pcb_app): фирменный
«пчелиный» стиль (золото на графите), тот же движок «Обновить с main», те же пресеты
тем (Dracula, Nord, Monokai, Tokyo Night, Матрица и ещё ~30) и свои профили настроек.

## Возможности

**Скетчи (как в Arduino IDE)**
- редактор C++ на CodeMirror 6 в духе PyCharm: **автодополнение кода** при наборе
  (функции и константы Arduino API, методы Serial/SPI/Wire/EEPROM после точки,
  `#include <…>`, свои идентификаторы) — навигация стрелками, выбор **Tab/Enter**,
  панель с описанием; Ctrl+Space вызывает список принудительно;
- богатая подсветка: ключевые слова, управляющие конструкции, типы, функции,
  константы (HIGH, INPUT…), объекты (Serial, SPI…), числа, строки, операторы и
  препроцессор — каждый своим цветом во всех темах;
- пары скобок, поиск/замена (Ctrl+F), свёртка кода, шаблоны setup+loop;
- вкладки файлов скетча (.ino, .cpp, .h, .c, .S, .hpp), добавление/закрытие файлов;
- скетчбук на диске сервера (`data/sketchbook`): открыть/сохранить/сохранить как/переименовать/удалить;
- автосохранение черновика в браузере;
- встроенные примеры (Blink, BlinkWithoutDelay, Fade, ToneMelody, Debounce, Smoothing,
  AnalogInOut, SerialEvent, Graph, Dimmer…) + примеры установленных плат и библиотек.

**Железо**
- компиляция (`Проверить`, Ctrl+R) и прошивка (`Загрузить`, Ctrl+U) через `arduino-cli`;
- выбор платы (все платы установленных ядер) и порта прямо в шапке, опрос портов раз в 4 с;
  **плата определяется автоматически**: воткнули Arduino — среда сама выберет порт и плату;
- менеджер плат: поиск и установка ядер (`arduino:avr`, `esp32`, …), удаление;
- менеджер библиотек: установленные / поиск по индексу / установка / удаление;
- установка самого `arduino-cli` одной кнопкой (скачивается с GitHub в `data/bin`, без системных прав);
- монитор порта: скорость до 115200, отправка строк с выбором конца строки, автопрокрутка, штампы времени;
- построитель графиков: рисует числа, которые печатает устройство (до 8 каналов).

**Оформление и настройки (порт из PSBees)**
- ~30 готовых тем + свои темы (свой акцент/фон/панели/текст), сохранение и удаление;
- пресеты вида интерфейса (Стандартный/Ноутбук/Минимализм/Отладка);
- свои профили настроек: вся конфигурация одним кликом;
- экспорт/импорт настроек файлом `micropide-settings.json`;
- настройки редактора (размер шрифта, перенос строк, показ пробелов), монитора порта, сборки.

**Автообновление (порт из PSBees)**
- фоновая проверка ветки `main` на GitHub: кнопка «Обновить» сама загорается и пульсирует;
- диалог с интерактивной полосой прогресса: этапы, скорость, ETA, отмена;
- два пути обновления: git-клон (`fetch` + `merge --ff-only`) или tar.gz-установка
  (скачивание → зависимости → сборка → подмена файлов, старая версия в `.update-cache/backup`);
- после установки сервер сам перезапускается, страница дожидается новой версии и перезагружается.

## Своё вместо серверов Arduino (автономный режим)

Серверы Arduino IDE (`downloads.arduino.cc`, индексы ядер и библиотек, GitHub-обновления)
могут быть недоступны — и без них среда остаётся рабочей. MicroPIDE умеет всё сама:

**Свой сборщик — компиляция без `arduino-cli`**
- собственный препроцессор скетча: главный `.ino` первым, `#line`-привязка ошибок к файлам,
  автогенерация прототипов функций, `#include` в начало (как это делает Arduino IDE);
- сборка по `platform.txt`/`boards.txt` любого ядра своим тулчейном (сначала ищется
  `compiler.path` из платформы, потом свои каталоги, склад, PATH);
- своя карта памяти: `nm`-символы, разбор `.elf` по секциям — видно, что именно съело флеш и ОЗУ;
- встроенный **симулятор на host-`g++`** (`micropide:sim:sim`): ядро Arduino с Serial/Wire/SPI/
  EEPROM/прерываниями разворачивается на месте, скетч собирается в обычный ELF и запускается
  как программа — логику можно проверить вообще без платы;
- **сборка под несколько плат** сразу: один скетч × FQBN-список, таблица «флеш/ОЗУ» по каждой.

**Своя база плат** (34 платы и 6 ядер внутри)
- характеристики МК, карта пинов (ШИМ, АЦП, прерывания, I2C/SPI/UART), «только вход»,
  служебные пины флеш-памяти, strapping-пины, VID:PID для автоопределения по USB;
- свои `package_index.json` / `library_index.json` — `arduino-cli` тоже работает офлайн;
- добавление своей платы прямо из UI (FQBN, МК, флеш/ОЗУ) — её видят и анализ, и сборщик.

**Склад и автономность**
- панель **Склад**: отчёт «автономность в %», что умеем без интернета, чего не хватает;
- загрузка архивов ядер/тулчейнов/библиотек прямо в браузере — с автоматическим распознаванием
  вида архива (`platform.txt` → ядро, `library.properties` → библиотека, бинарники → тулчейн);
- скачивание по зеркалам (GitHub-релизы) — если сеть всё-таки есть; иначе файл кладётся на склад
  руками, а среда сама распакует, установит и зарегистрирует ядро.

**Инструменты, которых нет в Arduino IDE**
- **Анализ скетча** (94/100 в примере): линтер под конкретную плату — конфликты пинов, ШИМ там,
  где его нет, `analogWrite` вне диапазона, регистры AVR, `String` в `loop()`, `delay()` в
  прерывании, «АЦП2 при включённом Wi-Fi» у ESP32, скорость Serial против монитора; каждая
  находка с подсказкой и автоправкой одной кнопкой;
- **карта пинов** наглядно: занятые/свободные, роли (ШИМ, АЦП, прерывание, I²C), конфликты,
  для каждого пина — строки кода, где он используется; имена пинов понимаются в т.ч. из
  `#define LED 13` и `const int BTN = 2`;
- **Генераторы**: `pins.h` с именами и особенностями платы, `MicroTelem.h` + пример,
  инструментирование `loop()` (замер времени итерации и свободной памяти);
- **Документация** на лету: README со схемой подключения (Mermaid), BOM и таблицей замечаний;
- **Телеметрия MicroTelem**: свой протокол (кадр `AA 55 | версия | каналов | CRC16 | float32×N`,
  плюс текстовые строки `#MT`), панель с графиками, легендой, экспорт CSV и PNG;
- **Тесты на железе и без железа**: свой язык сценариев `.mps` (`expect`, `expect_re`, `expect_pin`,
  `expect_pwm`, `adc`, `pulse`, `interrupt`…), запуск в симуляторе или на плате, отчёты в JUnit и TAP;
- **История**: снимки скетча при сохранении и сборке, дифф версий, возврат к любой версии,
  график роста флеш/ОЗУ по сборкам с предупреждениями о тренде;
- **Перенос скетча на другую плату**: подбор пинов по возможностям (по номерам каналов АЦП,
  сохранение номеров, где можно), автоматические адаптеры `analogReadResolution` /
  `analogWriteResolution`, предупреждения о 3.3 В, input-only, strapping, AVR-регистрах и
  `PROGMEM`, унифицированный дифф до применения;
- **Энергопрофиль**: оценка среднего тока и времени работы от батареи по коду (сон, `delay()`,
  радио, датчики, экраны, ШИМ) с советами «что убрать»;
- **Офлайн-справочник** по API (функции, методы, константы, библиотеки, приёмы MicroPIDE)
  с готовыми фрагментами кода и вставкой в редактор;
- **Шаблоны скетчей**: неблокирующее мигание, конечный автомат, сон для батарейных поделок,
  сканер I²C, телеметрия, watchdog, «карта пинов платы», готовый сценарий теста;
- **Скелет своей библиотеки** (`library.properties`, `keywords.txt`, `src/`, пример, README)
  и **класс-модуль** (`sensor`/`actuator`/`protocol`) — одним нажатием, запись в скетчбук.

**Командная строка** (`node bin/micropide.mjs …`)

```bash
micropide build Blink --fqbn arduino:avr:uno     # сборка своим движком
micropide sim Blink --mps tests/blink.mps        # прогон логики без платы
micropide test Blink --mps tests/blink.mps --junit out.xml
micropide analyze Blink --fqbn arduino:avr:uno   # линтер, --json для CI
micropide pins Blink | docs Blink --save README.md
micropide port Blink --to esp32:esp32:esp32 --write
micropide power Blink --battery 2000
micropide new Blink --template state_machine --fqbn arduino:avr:uno --write
micropide lib SensorKit --author "вы" --write
micropide boards esp32 | vault | templates | serve --port 8080
```

## Запуск

### Быстро — единый установщик

```bash
./install.sh        # Linux/macOS: поставит Node.js (если нет), зависимости, arduino-cli,
                    # платформу AVR и запустит на :8080
```

Windows: `install.cmd`. Подробный гайд — [INSTALL.md](INSTALL.md).

### Запуск одной командой (гайд)

Полный гайд — [ONE_COMMAND.md](ONE_COMMAND.md). Коротко:

```bash
git clone https://github.com/danilka-revin/micro-pide.git && cd micro-pide && ./install.sh
```

Windows: `git clone ... && cd micro-pide && install.cmd`. Уже установлено — `./run.sh`.

### ИИ-агент (работает вместо вас)

Подключите один API-ключ — и агент сам делает рутину. Подробности в
[ONE_COMMAND.md](ONE_COMMAND.md) (раздел «ИИ-агент») и [AGENTS.md](AGENTS.md).
Скрипт: `./agent.sh "задача"` (ключ в `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` /
`GEMINI_API_KEY`). API среды: `POST /api/agent`.

### Вручную

Нужен Node.js 18+.

```bash
./run.sh            # поставит зависимости, соберёт фронтенд и запустит сервер на :8080
./run.sh 3000       # на другом порту
./run.sh --build    # принудительная пересборка
```

Открыть `http://localhost:8080`. Разработка: `npm run dev` (vite, API проксируется на :8080)
и рядом `npm run server`.

### Проекты и библиотеки Arduino IDE

Если установлена Arduino IDE, MicroPIDE сам подхватывает её папки: проекты из
скетчбука (`~/Arduino` / `~/Documents/Arduino`), библиотеки из `libraries/` и
платы из `Arduino15` — с меткой **IDE** в панелях. Каталог можно сменить в
Настройках (Ctrl+,) в любой момент.

### arduino-cli

Без `arduino-cli` редактор и оформление работают, но компиляция/прошивка/монитор — нет.
Нажмите «Установить arduino-cli» в панели **Платы** — утилита скачается в `data/bin`
(данные: каталог `data`, скетчбук `data/sketchbook`; переопределяется переменными
`MICRO_PIDE_DATA` и `MICRO_PIDE_SKETCHBOOK`). Плоды ставятся в тот же каталог —
систему MicroPIDE не трогает. Можно и системный `arduino-cli` — он подхватится из PATH.

Порт сериального моста: сперва используется пакет `serialport` (опциональная зависимость),
если его нет — `arduino-cli monitor`.

## Структура

```
server/
  server.mjs         — HTTP-сервер: статика dist/, API, /version, /update/* (схема PSBees)
  arduino.mjs        — обёртка arduino-cli: поиск, установка, платы, библиотеки, compile/upload
  buildcore.mjs      — свой сборщик: препроцессор скетча, рецепты platform.txt, символы .elf
  native.mjs         — своё ядро симулятора на host-g++, сборка и запуск без платы
  analysis.mjs       — линтер под плату, карта пинов, оценка размера, документация, MicroTelem
  boarddb.mjs        — встроенная база плат и каталоги ядер/библиотек + свои индексы
  offline.mjs        — автономность: склад, зеркала, распознавание и установка архивов
  port.mjs           — перенос скетча на другую плату (пины, шины, адаптеры, дифф)
  power.mjs          — энергопрофиль: ток, сон, время работы от батареи
  scaffold.mjs       — шаблоны скетчей, скелет библиотеки, класс-модуль
  history.mjs        — снимки скетча, диффы, история сборок и тренд размера
  hiltest.mjs        — тесты .mps на симуляторе и на плате, отчёты JUnit/TAP
  scenario.mjs       — язык сценариев .mps и проверка ожиданий
  reference.mjs      — офлайн-справочник по API с фрагментами кода
  cpp.mjs            — разбор C++: маска кода, функции, вызовы, таблица констант, crc16
  routes.mjs         — все /api/* новых подсистем
  serialbridge.mjs   — серийный мост: serialport → arduino-cli monitor, буфер строк
  updater.mjs        — движок автообновления (check/run/status/cancel) — перенос PSBees
  sketches.mjs       — скетчбук на диске
bin/
  micropide.mjs      — командная строка: build/sim/test/analyze/pins/port/power/new/lib/serve
scripts/
  write-version.mjs  — dist/version.json (SHA сборки для автообновления)
src/
  App.tsx            — весь интерфейс: шапка-меню, панели, редактор, низ, статус-строка
  ui/                — дизайн-система PSBees: styles.css, icons, widgets, prefs, palette,
                       presets (темы), settings, updater (диалог обновления)
  ide/               — специфика IDE: api-клиент, редактор, примеры, консоль, монитор, панели,
                       анализ, история, тесты, телеметрия, склад, справочник
test/
  core.mjs           — тесты ядра: препроцессор, сборка, анализ, история, перенос, телеметрия
  server.mjs         — смоук-тест сервера (npm test)
  highlight.mjs      — правила раскраски вывода сборки
```

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Проверить (компилировать) | `Ctrl+R` |
| Загрузить в плату | `Ctrl+U` |
| Сохранить | `Ctrl+S` |
| Новый скетч | `Ctrl+N` |
| Открыть из скетчбука | `Ctrl+O` |
| Найти | `Ctrl+F` |
| Автодополнение | `Ctrl+Space`, выбор — `Tab` |

| Закомментировать строку | `Ctrl+/` |
| Монитор порта | `Ctrl+Shift+M` |
| Настройки | `Ctrl+,` |

```bash
npm test          # смоук сервера + правила раскраски вывода
node test/core.mjs # ядро: препроцессор, свой сборщик, анализ, история, перенос, телеметрия
```
