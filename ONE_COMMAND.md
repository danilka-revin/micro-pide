# MicroPIDE — запуск одной командой

Всё, что нужно: **одна команда** ставит Node.js (если его нет), зависимости,
сборку, `arduino-cli`, платформу AVR и запускает среду на `:8080`.

## Linux / macOS

```bash
git clone https://github.com/danilka-revin/micro-pide.git && cd micro-pide && ./install.sh
```

Откройте **http://localhost:8080** — готово.

Ключи (необязательны):

```bash
./install.sh --port 3000   # другой порт
./install.sh --no-avr      # не ставить AVR (Uno/Nano/Mega)
./install.sh --no-run      # только установить, не запускать
./install.sh --desktop     # ярлык в меню приложений (Linux)
```

## Windows (cmd / PowerShell)

```bat
git clone https://github.com/danilka-revin/micro-pide.git && cd micro-pide && install.cmd
```

`install.cmd` поставит Node.js через winget (если нет), соберёт проект,
скачает `arduino-cli`, поставит AVR и откроет браузер.

## Если уже установлено

```bash
./run.sh            # соберёт при необходимости и запустит на :8080
./run.sh 3000       # другой порт
./run.sh --build    # принудительная пересборка
```

## Что делает установщик (кратко)

1. Node.js 18+ (пакетный менеджер системы или архив в `.data/node`, без root).
2. `npm ci` / `npm install` + `npm run build` → `dist/`.
3. `arduino-cli` в `.data/bin/` (или берётся системный из PATH).
4. Платформа Arduino AVR (только если её ещё нет).
5. Старт сервера, печать адреса.

Повторный запуск безопасен: уже поставленное не перекачивается.

## ИИ-агент (работает вместо вас)

Подключите **один API-ключ** — и агент сам выполняет рутину: генерирует
скетчи, компилирует, прошивает, читает монитор порта, ставит платы/библиотеки.

### Вариант 1 — AI-помощник в репозитории (Cursor / Copilot / Claude Code / Aider)

В репозитории лежит файл `AGENTS.md` с полным контекстом проекта. Любой
современный ИИ-агент для кода подхватывает его автоматически:

```bash
# Claude Code
claude

# Aider (подключите ключ один раз)
export ANTHROPIC_API_KEY=sk-ant-...   # или OPENAI_API_KEY
aider

# Cursor / Copilot — просто откройте папку проекта
```

После этого агент знает структуру (`server/`, `src/`, `scripts/`), команды
сборки и тестов и может работать вместо вас: править код, запускать
`npm test`, собирать, коммитить.

### Вариант 2 — ключ в переменной окружения (одна команда)

```bash
export OPENAI_API_KEY=sk-...          # или ANTHROPIC_API_KEY / GEMINI_API_KEY
./agent.sh "собери и прошей Blink на Uno, порт /dev/ttyUSB0"
```

Скрипт `agent.sh` (и `scripts/agent.mjs`) берёт ключ из окружения, отправляет
задачу модели вместе с контекстом проекта и выполняет предложенные шаги
(компиляция/прошивка через `arduino-cli`, запуск тестов). Без ключа агент
отключён — ничего не делает.

### Вариант 3 — через API среды (`/api/agent`)

Сервер MicroPIDE предоставляет эндпоинт `POST /api/agent` (и `/api/ai`):
передайте `key` (API-ключ) и `task` (задача) — получите готовый ответ/план.
Ключ можно не передавать, если он задан в окружении сервера
(`OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY`).

```bash
curl -s http://localhost:8080/api/agent \
  -H 'Content-Type: application/json' \
  -d '{"key":"sk-...","task":"напиши Blink для Uno"}'
```

### Безопасность

- Ключ хранится локально (переменная окружения или `localStorage` браузера),
  в репозиторий и на сервер не отправляется.
- Агент не выполняет деструктивные команды без подтверждения.
- Отключить агент можно в любой момент: уберите ключ — и он перестаёт работать.

## Устранение неполадок

- «Порт не открывается» (Linux): `sudo usermod -aG dialout $USER`, перелогиньтесь.
- «arduino-cli не найден»: кнопка «Установить arduino-cli» в панели «Платы»
  или `node scripts/install-cli.mjs`.
- Порт 8080 занят: `./run.sh 3000`.
